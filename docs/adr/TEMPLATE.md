# ADR-NNNN — Short imperative title

- **Status:** Proposed | Accepted | Deferred | Superseded by ADR-NNNN
- **Date:** YYYY-MM-DD
- **Source:** where this was originally decided (doc §, or the code if it was decided in the writing)
- **Related:** other ADRs this constrains or depends on

## Context

The situation that forced a choice. What made the obvious option wrong, and what
the serious alternatives were. Write it so someone with no memory of the project
can tell whether the reasoning still holds.

## Decision

What was decided, in the present tense and specific enough to check code against.

## Consequences

What this buys and what it costs — both. Include the parts that are now harder,
the constraints other work has to respect, and anything that would trigger
revisiting this.
